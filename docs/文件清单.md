## 七、启动方式

1. 后端：`启动系统.bat`（自动启动后端 3000 + 前端 3001）或手动 `cd backend && node dist/main.js`
2. 前端：`npm run dev`（开发）或 `npm run build && npm run start -- -p 3001`（生产）
3. 移动端：`启动移动端.bat` 或 `cd frontend-mobile && npx expo start --port 8081`
4. 访问：`http://localhost:3001`　账号：`admin / admin123`
