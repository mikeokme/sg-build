# SG-Build 施工企业管理系统 · 整体架构规划

> 参照主流：钉钉 / 致远 OA（协同门户）+ 浪潮 GS（工程企业版）+ 广联达（工程业务）
> 原则：**先搭骨架 → 逐模块完善**（配置驱动，页面类型引擎）

---

## 一、三层总体架构

```
┌──────────────────────────────────────────────────┐
│ 门户层    领导驾驶舱 · 个人工作台 · 待办审批 · 公告通知 │
├──────────────────────────────────────────────────┤
│ 业务层    11 大业务中心                            │
│   协同办公 · 市场经营 · 项目管理 · 采购管理          │
│   物资管理 · 设备管理 · 财务管理 · 安全与质量         │
│   人力资源 · 平台中心 · 资源中心                    │
├──────────────────────────────────────────────────┤
│ 数据层    通用集合存储（内存） · 字段配置 · 种子数据    │
│ 平台层    权限(JWT+角色) · 审批流 · 预警 · 日志       │
└──────────────────────────────────────────────────┘
```

技术栈：Next.js 16 (App Router, Turbopack) + NestJS + 内存存储；PC Web 为主，Expo 移动端。

## 二、页面类型引擎（配置驱动核心）

每个功能通过 `features.ts` 注册，由 `pageType` 决定渲染组件：

| type | 组件 | 用途示例 |
|------|------|---------|
| `list` | FeaturePage | 各类台账：合同、订单、出入库单 |
| `dashboard` | StatPage | 领导驾驶舱、成本分析、采购报表 |
| `approval` | ApprovalPage | 审批中心（待办/我发起的/已办） |
| `gantt` | GanttPage | 施工进度、工期计划 |
| `calendar` | CalendarPage | 日程、会议、培训计划 |
| `doc` | DocPage | 公告、制度、知识库、公文 |

## 三、11 大业务中心功能清单

### 1. 协同办公（新增 · 对标钉钉/致远）
公告通知、审批中心、日程管理、会议管理、任务协作、文档中心、公文收发

### 2. 市场经营（对标浪潮经营）
客户档案、商机跟单、投标管理、投标结果、合同登记、项目立项

### 3. 项目管理（核心 · 对标广联达）
项目档案、项目策划、施工进度(甘特)、产值统计、施工预算、需用计划、租赁计划、分包计划、变更签证、竣工结算、预算报表

### 4. 采购管理
大宗采购请示、集采合同、采购合同、采购订单、租赁合同、分包合同、采购报表

### 5. 物资管理
需用计划明细、收料入库、入库折扣、领料出库、直入直出、调拨出入库、领料退库、物资退货、仓库管理、盘点管理、呆滞物料、物资台账

### 6. 设备管理（新增）
设备台账、设备租赁、设备调度、维护保养、故障维修、设备验收

### 7. 财务管理
资金管理、项目成本分析、发票管理、报销管理、付款管理、收款管理、费用报表

### 8. 安全与质量
安全处罚/奖励、安全培训、安全检查整改、安全事故、安全投入台账、质量处罚/奖励、质量培训、质量检查整改、质量事故

### 9. 人力资源
人事档案、考勤管理、班组管理、培训管理、奖惩记录、行政物资

### 10. 平台中心
信息管理(公告/制度/新闻)、审批中心、预警中心、日志中心、变更单

### 11. 资源中心（基础库）
客户档案、物料中心、供应商档案、项目库、施工班组、字典管理、权限管理、系统设置

## 四、实施阶段

- **阶段一（本次）**：页面类型引擎 + 模块扩充 + 门户工作台 + 种子数据 —— 骨架成型
- **阶段二**：协同办公细化（审批流、公告富文本、日程日历）
- **阶段三**：项目管理细化（甘特图、变更签证流）
- **阶段四**：驾驶舱数据可视化（统计图表、项目画像）
- **阶段五**：移动端对齐 + 权限细化 + 字典维护
